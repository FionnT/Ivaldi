This folder contains a custom builder for Neoterm.

Nuitka takes too long, and can't bundle PySide6 on MacOS unless it's installed in app mode, and in app mode CLI programs don't work great..

pycrucible is _almost_ perfect but it's not feature complete.

It's a great idea though, so we can take Nuitka, and compile a program that does the same thing as pycrucible - but just exactly for what we need it to do.
